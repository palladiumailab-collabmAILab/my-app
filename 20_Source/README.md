# Source

This folder is the dedicated home for source-side implementation materials.

| Path | Purpose |
| --- | --- |
| `src/` | Python package source |
| `tests/` | Test suite |
| `infra/` | Docker and infrastructure implementation files |
| `scripts/` | Source-specific development, build, test, formatting, or release helpers |

Scripts for other domains must live with that domain. For example,
knowledge-vault scripts belong under `30_KnowledgeVault/scripts/`.

Do not place rules, generated specification documents, or knowledge-vault
operation files in this folder.
