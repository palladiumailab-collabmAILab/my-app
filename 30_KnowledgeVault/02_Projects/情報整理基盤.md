# 情報整理基盤

## Outcome

思いつきで話したり聞いたりした内容を、Obsidian と GitHub を使って AI が整理・保守できる状態にする。

## Operating Principle

人間は整理しなくていい。まず `00_Inbox/` に投げる。AI があとで意味、関係、次アクション、保存先を整える。

## Current State

- `30_KnowledgeVault/` を Obsidian vault として使う。
- 情報の主入口はGitHub Issueにする。
- スマホでは `AI Inbox` に記事、URL、画像、メモを貼る。
- 聞き出しは `AI Question` issueを使う。
- 補助入口は Siri、Gemini、Web版LLM、URL貼り付け、手動メンテの5つにする。
- どの入口でも頼み方は「インボックス化して」に統一する。
- 入口ごとの保存先は `00_Inbox/{source}/` に分ける。
- GitHub で履歴とバックアップを管理する。
- AI の運用ルールは `90_Meta/AI/` に置く。
- テンプレートは `90_Meta/Templates/` に置く。
- 個人端末の Obsidian workspace 状態は Git 管理しない。
