# Knowledge Helper Scripts

This folder contains PowerShell helpers for creating and maintaining notes in
`30_KnowledgeVault/`.

| Script | Purpose |
| --- | --- |
| `new-ai-capture-note.ps1` | Create an AI capture note |
| `new-daily-note.ps1` | Create a daily note |
| `new-inbox-note.ps1` | Create an inbox note |
| `new-url-note.ps1` | Create a URL note |
