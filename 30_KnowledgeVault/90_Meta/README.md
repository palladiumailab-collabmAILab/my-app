# Vault Meta

This folder stores templates and operating rules for the knowledge vault.

- `Templates/` contains reusable Obsidian note templates.
- `AI/` contains instructions for AI-assisted organization.

Keep operational rules here so Codex and other AI tools can maintain the vault consistently.

Start with:

- `AI/github-mobile-inbox.md` for the simplest GitHub app based mobile workflow.
- `AI/short-commands.md` for short Codex commands such as `inbox`, `質問`, and `全部`.
- `AI/unified-capture.md` for the single prompt used across all entrances.
- `AI/entrypoints.md` for Siri, Gemini, Web LLM, URL, and manual capture.
- `AI/mobile-setup.md` for mobile capture setup notes.
- `AI/iphone-siri-setup.md` for the iPhone Siri shortcut setup.
- `AI/ai-operating-manual.md` for the default AI triage workflow.
