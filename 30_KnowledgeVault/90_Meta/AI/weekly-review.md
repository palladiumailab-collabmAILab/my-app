# Weekly Review

Use this checklist when the owner asks for a vault review.

## Inbox

- [ ] Process every note in `00_Inbox/`.
- [ ] Extract tasks into project or area notes.
- [ ] Create permanent notes only for reusable ideas.
- [ ] Archive fully processed raw notes when safe.

## Projects

- [ ] Mark completed projects as done.
- [ ] Identify stuck projects.
- [ ] Make sure every active project has a next action.
- [ ] Link related resources and decisions.

## Areas

- [ ] Update dashboards for ongoing responsibilities.
- [ ] Remove stale tasks.
- [ ] Surface neglected areas.

## Knowledge Quality

- [ ] Merge obvious duplicates.
- [ ] Add missing links where they help retrieval.
- [ ] Flag sensitive information before commit.
- [ ] Summarize unresolved questions.

## Output

End with:

- What changed
- What needs attention
- What can be ignored for now
